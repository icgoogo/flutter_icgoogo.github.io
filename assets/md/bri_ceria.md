### Overview

Contributed to **BRI Ceria**, a digital lending platform serving over 1,000,000 users. Focused on cross-platform mobile development, secure API communications, and CI/CD pipeline integration.

#### Key Security & Engineering Contributions

- **Vulnerability Remediation**: Hardened mobile security based on **OWASP MASVS** guidelines following third-party penetration testing.
- **Data-in-Transit Protection**: Implemented secure client-backend handshake protocols and request verification mechanisms across core banking middleware.
- **Flutter Migration**: Migrated legacy native Java code to Flutter, reducing APK size from **100 MB to 50 MB**.
- **System Resilience**: Improved error handling and app stability, raising crash-free user rate from **88% to over 99.5%**.
