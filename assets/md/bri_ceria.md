### Main Responsibility

Contributed to the engineering and maintenance of BRI Ceria, a digital lending platform serving **1M+ users**. My primary responsibility was mobile application development, while I also supported several services integrating data from core banking and middleware systems and built automated pipelines to accelerate software delivery. More info: [Ceria by BRI](https://bri.co.id/en/ceria2)

#### Key Contributions

- **App Stability**: Increased crash-free user sessions from 88% to over 99.5% through aggressive state management refactoring, memory leak resolution, and proactive error handling.
- **Footprint Optimization**: Reduced the total application package size by 50% (from ~100 MB to ~50 MB), lowering user drop-off rates during installation.
- **Fraud Mitigation**: Redesigned the end-to-end digital lending onboarding flow and designed a behavioral fraud detection system using historical customer data.
- **Security & Compliance**: Hardened application security following OWASP MASVS standards post-penetration testing, implementing custom SSL pinning and cryptographic handshake mechanisms between client apps and API gateways.
- **Integration Pipelines**: Built and maintained CI/CD pipelines with Jenkins for deployments of front app and microservices integrating middleware with core banking infrastructure.
