5G Throughput Forecasting via LSTM & Vertical Federated Learning
Data Source: https://www.nature.com/articles/s41597-025-06282-0
Time-Series Modeling: Built LSTM networks to forecast temporal 5G throughput, benchmarking performance against Random Forest baselines
Privacy-Preserving ML: Implemented a simulated Vertical Federated Learning (VFL) framework to enable collaborative throughput prediction across feature domains without sharing raw telemetry data.
